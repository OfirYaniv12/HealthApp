# Archive

Old one-off helper scripts, patches and test files that were created while building the app
(mostly by the previous AI editor). None of them are used by the app, the build, or Vercel.

They were moved here (not deleted) to keep the project root clean. Safe to delete once you're
sure you don't need any of them.

- `root-scripts/` – former files from the project root (`fix_*.js`, `fix*.py`, QR helpers, logs...)
- `tmp/` – former `tmp/` folder (Gemini API experiments)
- `utils/` – old copies of `utils/ai.ts` (`ai_fixed.ts`, `ai_safe_backup.ts`)
